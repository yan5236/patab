# PaTab 自定义组件安全说明

PaTab 自定义组件是用户本地导入的第三方 ZIP，不属于 PaTab 审核或托管的软件。安装前请确认开发者身份、签名事实、权限与精确 HTTPS 网络来源；即使签名有效，也只表示包与该公钥匹配，不表示 PaTab 对组件内容作出安全保证。

## PaTab 会做什么

- 导入只接受 `.zip` 与 `.patab.zip`，限制压缩包、解压体积、文件数、单文件大小、路径与 ZIP 元数据；不在浏览器中安装依赖或构建源码。
- 安装前只校验 Manifest、静态图片、完整性和签名。审查页不会插入或执行 package HTML，也不会创建第三方 iframe。
- 已安装 surface 只能在不含 `allow-same-origin` 的 `sandbox="allow-scripts"` iframe 中运行。Web 使用 `srcdoc`，MV3 使用固定 sandbox page 加唯一内层 iframe；第三方不能直接访问宿主 DOM、Pinia、localStorage 或扩展 API。
- surface 自身 CSP 默认禁止直接网络、外部脚本、外部样式、表单、导航和对象。它只能经 Capability Broker 调用已公开、已授权的 API。
- 待办、实例存储、网络、外链与宿主 UI 都由 Broker 逐次检查组件、实例、会话、消息格式、权限、大小与频率。错误不会展示组件私有数据、请求正文、Authorization、宿主堆栈或本机路径。
- 组件包、授权、回滚版本与私有数据位于独立 IndexedDB；主屏 localStorage 只保留轻量实例引用。更新、卸载与配额写入使用原子事务。

## 用户仍需承担的风险

- sandbox 无法提供可靠的 CPU 或内存硬配额。恶意无限循环可能影响当前渲染进程；PaTab 以启动标记、自动停用与安全模式降低重复执行风险。
- 允许的网络 origin 仍可能处理组件主动发送的数据。只授权你理解且信任的精确 HTTPS origin，并尽量不给可选权限。
- 未签名包可以安装，但更新时无法提供发布者身份连续性。签名无效或公钥变化的包不能覆盖现有组件。
- Web 网络请求受目标服务 CORS 限制；PaTab 不会通过不安全代理绕过 CORS。扩展的 host permission 由浏览器保存，且可以被用户随时撤销。

## 安全使用建议

1. 只从可信开发者取得 ZIP，并在安装前核对组件名称、版本、开发者、签名、权限和网络用途。
2. 把只读或可选权限保持关闭，除非确实需要；不要为不明用途授予待办写权限或网络来源。
3. 组件异常、反复超时或出现停用原因时，不要立即重新启用。先移除不可信实例，必要时完全卸载。
4. 安全模式会阻止所有第三方 iframe，但保留组件管理和卸载入口。退出安全模式后，PaTab 不会自动恢复旧实例。
5. 卸载确认后会删除包、授权、所有实例、私有数据、健康记录与回滚版本；需要保留内容时，先在组件自己的可见功能中完成导出。

开发者需要的产物约束与签名流程见[自定义组件开发指南](./custom-component-development.md)。
